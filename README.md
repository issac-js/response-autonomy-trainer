# Response Autonomy Trainer｜沟通决策训练系统 v0.4.1

本版是 v0.4.0 的**缺陷修复版**：沿用 v0.4.0 全部功能，只修复实测发现的缺陷并补充验收。默认开启三个可选触发点（A 怕尴尬、B 自动接话、D 怕被误解，可在应用内自行调整），把知识复习、三轮模拟和低风险真实交流观察连接起来；目标是更熟练地按情境回应，不承诺治愈焦虑或形成永不失误的条件反射。

通用设计说明见 `TRAINING_DESIGN.md`。个人化的训练记录只保存在本机浏览器与其导出的 JSON 中，不随仓库分发。

存储键 `response-autonomy-v01`、`version:1`、`schemaVersion:3` 与字段结构**完全未变**，不需要迁移，可回退到 v0.4.0。本次只把 `appVersion` 元数据从 `0.4.0` 改为 `0.4.1`。

## 立即使用

解压后用 Edge/Chrome 双击 `index.html`（单文件离线版，也可直接打开本目录内同版 `index.html`）。无需账号或网络。

1. 进入“自主回应练习”，在“模拟练习”中任选一个可承受的单元；14个单元可重复、跳过，不是14天打卡。
2. 先写担心的结果，或写“还不确定”。不适程度可不记。
3. 每轮先写原话，可选录音回听、记录想追加的解释。锁定后再选择最接近的行动，进入固定后续情节。没有匹配选项可选“其他”。
4. 完成三轮后再复盘：哪些信息必要？是否在用解释消除不安？是否仍能正常履职？**没有语义自动判分**。
5. 有合适机会时打开“真实交流”，提前保存一个低风险情境、预测和小动作。稍后补充实际观察；未回复、反应不理想或未知，都可以如实记录。
6. 在“复盘记录”区分模拟和真实证据。每次记录一次即可，不必反复检查。
7. 在“复习相关判断卡”中按触发点复习。最多3张，优先到期卡，再使用每日剩余新卡额度。卡片库也可自主加练。FSRS只安排知识复习，不判断焦虑改善。

## 保存与恢复边界

- 已确认或已保存的模拟草稿、真实计划与观察照旧写入 `response-autonomy-v01`，导出 JSON 包含这些记录。
- **尚未提交的输入**另有一份本标签页临时草稿（`sessionStorage` 独立键 `response-autonomy-v01-unsaved-v1`）：导航、切换视图、重新打开相同表单或刷新后可恢复；离开/刷新前浏览器会提示；顶部提示条可一键清除。它不进入学习记录、不进入 JSON 备份、不上传、关闭标签页即清除。
- 练习卡片与多轮模拟的**临时进度（题号、队列、阶段）**在刷新后不恢复；文字会提示但不会串到另一张卡。
- 录音只在本题临时回听，不上传、不保存到 JSON；导航离开本题清除并释放麦克风。麦克风不可用时仍可文字练习。
- 导入/重置仍按用户确认替换记录；导入前可导出当前备份。不同设备通过 JSON 迁移。请关闭旧版页面，防止旧客户端写入。

## 应用图标

图标语义是「对话中的一拍」：深紫圆角底、白色对话气泡、两条深色暂停竖条，对应训练的核心动作——开口前先判断，再决定回应多少。

- `assets/icon.svg`：大尺寸细节版（气泡＋尾巴＋双光源背景）。
- `assets/icon-compact.svg`：16/20/24/32 像素的简化版，只保留两条暂停竖条，避免小尺寸糊成一团。
- `assets/icon.ico`：10 帧（16–256）多尺寸图标；`assets/icon-*.png` 为各尺寸位图。
- `tools/render-icon.cjs`：可选重建脚本，需要 Playwright；日常 `rebuild.py` 不需要。
- `rebuild.py` 会把 32/64 像素图标以 data URI 内联进单文件，并写入 `theme-color`，离线打开也会显示正确 favicon。

主色与界面一致：底 `#1C1136 → #56379B`，气泡 `#FFFFFF`，竖条 `#3A2370 → #1F1238`。

## 从旧版迁移与回滚

在旧版导出 JSON，保留原备份并关闭旧版页面，再在本版“设置与备份”中导入。不同 `file://` 路径的浏览器存储可能不同，不依赖自动继承。

导入 v0.1/v0.2/v0.3/v0.4.0 时保留原 `cards`/`history`/`dialogueHistory`/`writes`/FSRS，到期日不重算，schemaVersion 在内存升为 3，下一次明确保存时写入；新增空白个人练习数据，不造学习记录。旧 v0.3 应用会拒绝 schema3 数据，回退到旧版请用升级前备份。

导入先完整校验 → 写入新记录 → 再写“导入前快照”；任一步失败都不会留下误导性的旧快照。导入上限 20MB；本地空间不足时明确报错，不静默截断历史。请定期导出，备份包含你的原话和真实交流记录，应先脱敏。

**回滚到 v0.4.0**：本版未改存储结构，可直接把升级前备份导入 v0.4.0；也已实测 v0.4.1 导出的完整备份可无损导入原始 v0.4.0。详见 `DELIVERY_v0.4.1.md`。

## 项目文件

- `index.html`：重建后的完整单文件离线应用。
- `template.html` / `app.js`：结构样式、原有页面和八套多轮模拟。
- `data.js`：数据校验、迁移、存储和固定版本 FSRS。
- `form-guard.js`：未提交输入的本标签页临时草稿与离开前提示（不触碰主记录）。
- `assets/`：图标源文件与多尺寸位图；`tools/render-icon.cjs` 为可选重建脚本。
- `single.js` / `settings.js` / `voice.js`：单轮、备份和临时录音。
- `coach-data.js`：14个单元、六类场景、触发点与新数据校验。
- `coach.js`：模拟、草稿、真实计划/观察和分开统计。
- `cards.json` / `dialogues.json`：原题库源，与 v0.3 逐字节一致。
- `vendor/`：原官方 ts-fsrs 5.4.2 UMD 与完整 MIT 许可。
- `tests/`：合成样例测试、结果与浏览器兼容性检查；不含用户真实记录。
- `DELIVERY_v0.4.1.md`：变更说明、实测结果、未通过项、迁移/回滚方法。
- `.markdownlint-cli2.jsonc`：中文文档校验配置；5 份 `.md` 通过双校验。

运行 `python3 rebuild.py` 重建单文件，不需 npm。运行 `node tests/core.cjs` 执行核心检查，`node tests/regression.cjs` 执行存储回归。浏览器测试依赖 playwright 与 Chromium：`node tests/browser.cjs`、`node tests/coach-browser.cjs`、`node tests/regression-browser.cjs`、`node tests/compat.cjs`、`node tests/rollback.cjs`；可通过 `PLAYWRIGHT_MODULE` 指定模块位置、`PLAYWRIGHT_BROWSERS_PATH` 指定浏览器缓存、`RAT_BASELINE_HTML` 指定 v0.4.0 基线、`RAT_BASELINE_PATH` 指定 v0.2 基线。浏览器脚本在基线或引擎缺失时记录阻塞/跳过，**不把未执行的项算作通过**。

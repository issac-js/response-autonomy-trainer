# Response Autonomy Trainer｜沟通决策训练系统 v0.4.2

v0.4.2 是 v0.4.1 的**草稿保护增量修复版**：不改题库、FSRS、主存储结构，只修复独立复核发现的 F1/F2/F3 并更正文档口径（F4）。默认开启三个可选触发点（A 怕尴尬、B 自动接话、D 怕被误解，可在应用内自行调整），把知识复习、三轮模拟和低风险真实交流观察连接起来；目标是更熟练地按情境回应，不承诺治愈焦虑或形成永不失误的条件反射。

通用设计说明见 `TRAINING_DESIGN.md`。个人化的训练记录只保存在本机浏览器与其导出的 JSON 中，不随仓库分发。

## 立即使用

解压后用 Edge/Chrome 双击 `index.html`（单文件离线版）。无需账号或网络。

1. 进入“自主回应练习”，在“模拟练习”中任选一个可承受的单元；14个单元可重复、跳过，不是14天打卡。
2. 先写担心的结果，或写“还不确定”。不适程度可不记。
3. 每轮先写原话，可选录音回听、记录想追加的解释。锁定后再选择最接近的行动，进入固定后续情节。没有匹配选项可选“其他”。
4. 完成三轮后再复盘：哪些信息必要？是否在用解释消除不安？是否仍能正常履职？**没有语义自动判分**。
5. 有合适机会时打开“真实交流”，提前保存一个低风险情境、预测和小动作。稍后补充实际观察；未回复、反应不理想或未知，都可以如实记录。
6. 在“复盘记录”区分模拟和真实证据。每次记录一次即可，不必反复检查。
7. 在“复习相关判断卡”中按触发点复习。最多3张，优先到期卡，再使用每日剩余新卡额度。卡片库也可自主加练。FSRS只安排知识复习，不判断焦虑改善。

## 保存与恢复边界

- 已确认或已保存的模拟草稿、真实计划与观察写入 `response-autonomy-v01`，导出 JSON 包含这些记录。
- **尚未提交的输入**另存为本标签页临时草稿（`sessionStorage` 独立键 `response-autonomy-v01-unsaved-v2`），按「分组 + 归属 + 节点 + 字段」精确隔离：
  - 单轮卡片按卡片编号隔离，重新打开**同一张卡**会恢复原话，不会填到另一张卡；
  - 多轮模拟按情境与轮次隔离，并额外保存未完成的会话进度，重新打开**同一情境**会回到原轮次继续；
  - 真实计划 / 观察按记录 id 精确隔离，`a` 与 `a:b` 这类前缀 id 互不影响。
- 草稿只在该回答保存成功或用户明确放弃时清除；顶部提示条可一键清除全部临时草稿。它不进入学习记录、不进入 JSON 备份、不上传、关闭标签页即清除。
- 练习队列本身（今天还剩哪些卡、当前阶段）在刷新后重置，但**已写的原话不会丢**；重新打开同一张卡即可继续。
- 录音只在本题临时回听，不上传、不保存到 JSON；导航离开本题清除并释放麦克风。麦克风不可用时仍可文字练习。
- 导入/重置仍按用户确认替换记录；导入前可导出当前备份。不同设备通过 JSON 迁移。请关闭旧版页面，防止旧客户端写入。

## 从旧版迁移与回滚

在旧版导出 JSON，保留原备份并关闭旧版页面，再在本版“设置与备份”中导入。不同 `file://` 路径的浏览器存储可能不同，不依赖自动继承。

导入 v0.1/v0.2/v0.3/v0.4.x 时保留原 `cards`/`history`/`dialogueHistory`/`writes`/FSRS，到期日不重算，schemaVersion 在内存升为 3，下一次明确保存时写入；新增空白个人练习数据，不造学习记录。旧 v0.3 应用会拒绝 schema3 数据，回退到旧版请用升级前备份。

导入先完整校验 → 写入新记录 → 再写“导入前快照”，并按三种情况如实提示：有旧记录且快照成功 / 没有旧记录无需快照 / 快照写入失败需立即导出。导入上限 20MB；本地空间不足时明确报错，不静默截断历史。请定期导出，备份包含你的原话和真实交流记录，应先脱敏。

**回滚到 v0.4.0**：本版未改存储结构，可直接把升级前备份导入 v0.4.0；也已实测当前构建导出的完整备份可无损导入原始 v0.4.0。详见 `DELIVERY_v0.4.2.md`。

## 应用图标

图标语义是「对话中的一拍」：深紫圆角底、白色对话气泡、两条深色暂停竖条，对应训练的核心动作——开口前先判断，再决定回应多少。

- `assets/icon.svg`：大尺寸细节版（气泡＋尾巴＋双光源背景）。
- `assets/icon-compact.svg`：16/20/24/32 像素的简化版，只保留两条暂停竖条，避免小尺寸糊成一团。
- `assets/icon.ico`：10 帧（16–256）多尺寸图标；`assets/icon-*.png` 为各尺寸位图。
- `tools/render-icon.cjs`：可选重建脚本，需要 Playwright；日常 `rebuild.py` 不需要。
- `rebuild.py` 会把 32/64 像素图标以 data URI 内联进单文件，并写入 `theme-color`，离线打开也会显示正确 favicon。

主色与界面一致：底 `#1C1136 → #56379B`，气泡 `#FFFFFF`，竖条 `#3A2370 → #1F1238`。

## 项目文件

- `index.html`：重建后的完整单文件离线应用。
- `template.html` / `app.js`：结构样式、原有页面和八套多轮模拟。
- `data.js`：数据校验、迁移、存储和固定版本 FSRS。
- `form-guard.js`：未提交输入的本标签页临时草稿、精确隔离与离开前提示（不触碰主记录）。
- `single.js` / `settings.js` / `voice.js`：单轮、备份和临时录音。
- `coach-data.js`：14个单元、六类场景、触发点与新数据校验。
- `coach.js`：模拟、草稿、真实计划/观察和分开统计。
- `assets/`：图标源文件与多尺寸位图；`tools/render-icon.cjs` 为可选重建脚本。
- `cards.json` / `dialogues.json`：原题库源，与 v0.3 逐字节一致。
- `vendor/`：原官方 ts-fsrs 5.4.2 UMD 与完整 MIT 许可。
- `tests/`：合成样例测试、结果与浏览器兼容性检查；不含用户真实记录。
- `DELIVERY_v0.4.2.md`：本版变更说明、实测结果、未通过项、迁移/回滚方法。
- `DELIVERY_v0.4.1.md`：上一阶段记录，保留作历史对照。
- `.markdownlint-cli2.jsonc`：中文文档校验配置；所有 `.md` 通过双校验。

运行 `python3 rebuild.py` 重建单文件，不需 npm。运行 `node tests/core.cjs` 执行核心检查，`node tests/regression.cjs` 执行存储回归。浏览器测试依赖 playwright 与 Chromium：`node tests/browser.cjs`、`coach-browser.cjs`、`regression-browser.cjs`、`draft-regression.cjs`、`http-origin.cjs`、`compat.cjs`、`rollback.cjs`；可通过 `PLAYWRIGHT_MODULE` 指定模块位置、`PLAYWRIGHT_BROWSERS_PATH` 指定浏览器缓存、`RAT_BASELINE_HTML` 指定 v0.4.0 基线、`RAT_BASELINE_PATH` 指定 v0.2 基线。缺失依赖时脚本记录阻塞或跳过，**不把未执行的项算作通过**。
